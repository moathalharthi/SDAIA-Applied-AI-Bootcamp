# SDAIA Applied AI Bootcamp
---
## About the Program

The **Applied AI Bootcamp** is run by SDAIA (Saudi Data and Artificial Intelligence Authority). It covers the full AI engineering stack across multiple courses — from Python and data science fundamentals through machine learning pipelines, deep learning, and building production agentic AI systems with LLMs.

**Organizer:** SDAIA Academy  
**Location:** Riyadh, Saudi Arabia  
**Duration:** March 29 – May 21, 2026 (In-person, full-time)

---

## Courses & Modules

### 1. Python

| Module | Topics |
|---|---|
| Python Syntax | Scripting, Control Flow, Functions |
| Collections | Sequences, Dictionaries, Text Files, Iteration |
| Programming Paradigms | OOP, Functional Programming, Error Handling, APIs |

---

### 2. Applied Data Science

| Module | Topics |
|---|---|
| Introduction | Data Science roles, EDA vs CDA, outlier analysis |
| Data Wrangling | Pandas, groupby, reshaping, time series, function application |
| Statistical Analysis | Univariate stats, distributions, box plots, seaborn visualizations |
| Inferential Statistics | Hypothesis testing, p-values, bivariate analysis, Chi-square, Cramer's V |

**Projects:**
- Fast Food Marketing Campaign A/B Test
- Student Exam Performance Factors
- Global Mental Health Crisis Index 2026

---

### 3. Applied Machine Learning

| Module | Topics |
|---|---|
| Linear Models | Linear & Logistic Regression, train/test split |
| Non-linear Patterns | Polynomial Features, Spline Transformer, Decision Trees |
| Predictive Pipelines | Missing data, scaling, encoding, `Pipeline`, `ColumnTransformer` |
| Model Evaluation | Cross-validation, overfitting/underfitting, generalization |
| Hyperparameter Tuning | Grid Search, Random Search |
| Regression Metrics | MAE, MSE, R², MAPE, residual plots |
| Classification Metrics | Confusion matrix, ROC/PR curves, threshold tuning, Precision/Recall |
| Ensembles | Random Forests, Bagging, Boosting |
| AutoML | AutoGluon |

---

### 4. Agentic AI
